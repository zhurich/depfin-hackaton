# iOS-оболочка «Питомец Финни»

Порт приложения на iOS по той же схеме, что и Android: тонкая нативная
оболочка с полноэкранным `WKWebView`, внутри которого работает тот же самый
веб-слой из [`../web`](../web). Игровая логика, контент и интерфейс не
дублируются — обе платформы собирают один и тот же `web/dist`.

> iOS не входит в обязательный конкурсный минимум (ТЗ п. 3.2: «Адаптация под
> iOS — по желанию команды»), поэтому этот порт ничего не заменяет в сдаче.

## Требования

| Инструмент | Версия |
| --- | --- |
| macOS | 13 и новее |
| Xcode | 15 и новее |
| Node.js | ≥ 20 |
| XcodeGen | любая свежая (`brew install xcodegen`) |

Минимальная версия iOS — **15.0**.

## Сборка

```bash
# 1. Собрать веб-слой (кладётся в web/dist и раскладывается по оболочкам)
cd web
npm ci
npm run build

# 2. Сгенерировать Xcode-проект
cd ../ios
xcodegen

# 3. Открыть и запустить
open FinniPet.xcodeproj
```

В Xcode выберите таргет **FinniPet**, симулятор или устройство и нажмите Run.
Для запуска на устройстве укажите свою команду разработчика в
**Signing & Capabilities**.

### Без XcodeGen

Если ставить XcodeGen не хочется:

1. Xcode → File → New → Project → App, имя `FinniPet`, интерфейс Storyboard,
   язык Swift.
2. Удалить сгенерированные `ViewController.swift`, `Main.storyboard` и запись
   `UIMainStoryboardFile` из Info.plist.
3. Перетащить в проект содержимое `FinniPet/` (Swift-файлы, `Assets.xcassets`,
   `Base.lproj/LaunchScreen.storyboard`), заменив Info.plist на здешний.
4. Перетащить каталог `FinniPet/www` **как folder reference** (синяя папка,
   «Create folder references»), иначе структура каталогов внутри пакета
   потеряется и страница не загрузится.
5. Bundle Identifier — `ru.mosfin.finnipet`.

## Устройство оболочки

| Файл | Назначение |
| --- | --- |
| [`WebViewController.swift`](FinniPet/WebViewController.swift) | Экран с `WKWebView`: загрузка, возврат по краевому свайпу, масштаб текста, очистка данных |
| [`AssetSchemeHandler.swift`](FinniPet/AssetSchemeHandler.swift) | Отдаёт `www` по схеме `finni-assets://app/` — аналог `WebViewAssetLoader` из Android |
| [`NativeBridge.swift`](FinniPet/NativeBridge.swift) | Принимает команды веб-слоя (`saveProfile`, `clearProfile`, `clearAllData`) |
| [`ProfileStore.swift`](FinniPet/ProfileStore.swift) | Хранит профиль файлом в Application Support |

### Чем iOS отличается от Android

| Что | Android | iOS | Почему |
| --- | --- | --- | --- |
| Отдача файлов | `WebViewAssetLoader` по https | `WKURLSchemeHandler` по `finni-assets://` | WKWebView не даёт переопределить `https`; собственная схема так же даёт странице нормальный источник |
| Мост | `addJavascriptInterface`, вызовы синхронные | `postMessage`, только в одну сторону | Ограничение WKWebView. Всё, что нужно прочитать, оболочка внедряет в `window` до загрузки страницы |
| Хранение профиля | `localStorage` | Файл на стороне оболочки | Доступность веб-хранилища для собственных схем в WebKit менялась от версии к версии; терять прогресс нельзя |
| Возврат | Системная кнопка «Назад» | Краевой свайп слева | На iOS нет аппаратной кнопки. Оба ведут в один обработчик `window.finniHandleBack()` |
| Системный размер шрифта | `WebSettings.textZoom` | `WKWebView.pageZoom` | На iOS масштабируется страница целиком — вёрстка задана в пикселях, так ничего не разъезжает |
| Закрытие приложения | Возврат с главного экрана закрывает | Не закрывается | Принято на платформе: приложения не закрывают себя сами |

Разрешений не запрашивается ни одного, сетевых запросов приложение не делает,
переходы за пределы собственной схемы заблокированы.

## Проверка после сборки

1. **Экран не пустой.** Если пусто — почти наверняка не собран веб-слой или
   `www` подключён как группа, а не как folder reference. Проверьте, что в
   собранном пакете есть `www/index.html`.
2. **Прогресс переживает перезапуск.** Создайте питомца, купите что-нибудь,
   снимите приложение из списка задач, запустите заново. Это главная проверка:
   именно ради неё профиль хранит оболочка, а не браузер.
3. **Раздел для взрослого → «Данные на устройстве»** показывает
   «Платформа: iOS» и «Где хранится профиль: в приложении». Если написано
   «в хранилище браузера» — внедрение `FinniNativeStorage` не сработало.
4. **«Удалить все данные»** возвращает приложение к знакомству.
5. **Краевой свайп слева** на экране словарика или задания возвращает назад.
6. **Системный размер шрифта** (Настройки → Экран и яркость → Размер текста) —
   интерфейс масштабируется и ничего не обрезается.
7. **Безопасные зоны**: шапка не заезжает под «чёлку», нижние вкладки — под
   полосу жестов.
8. **Шрифты**: заголовки Nunito, текст Onest, кириллица не подменяется
   системным шрифтом.
9. **Режим полёта** — игра работает полностью.

## Публикация

RuStore — магазин только для Android, поэтому карточка из
[`../docs/RUSTORE-LISTING.md`](../docs/RUSTORE-LISTING.md) к iOS не относится.
Для App Store потребуется отдельно: учётная запись разработчика, иконка
1024 × 1024 (см. [APP-ICON.md](APP-ICON.md)), скриншоты под требуемые размеры
экранов, политика конфиденциальности и заполненная форма App Privacy — в ней
указывается «Data Not Collected», поскольку приложение не собирает данные.

Возрастной рейтинг — 4+ по анкете App Store: насилия, пользовательского
общения, рекламы и покупок в приложении нет.
