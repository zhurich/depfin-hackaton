## 2. Ручные тест-кейсы

Проходятся на устройстве по финальной сборке. Перед началом включите
демонстрационный режим и сбросьте тестовый профиль: **Раздел для взрослого →
решить пример → «Демонстрационный режим» → «Сбросить профиль к началу»**.

### ТК-01. Первый запуск и знакомство (шаг 1)

1. Установить APK, запустить.
2. Пролистать четыре слайда знакомства.

**Ожидается:** приложение открывается до стартового экрана не более чем за 5 с;
показаны три типа решений — потратить на обязательное, потратить на желаемое,
отложить; кнопка «Пропустить» доступна на первом слайде.

### ТК-02. Создание профиля без персональных данных (шаги 2–3)

1. Выбрать вид, цвет и аксессуар питомца.
2. Нажать «Удиви меня» — вид меняется случайно.
3. Ввести игровое имя питомца и игровое имя игрока.

**Ожидается:** превью питомца обновляется сразу; не запрашиваются настоящее имя,
телефон и e-mail; виден блок «Без регистрации»; кнопка «Готово» неактивна, пока
не заполнены оба имени.

### ТК-03. Стартовый бюджет и главный экран (шаг 4)

**Ожидается:** начислено 120 Ф с подписью «Стартовый бюджет»; на главном экране
одновременно видны питомец, баланс, накопления, цель, три показателя состояния,
активное задание и переходы во все разделы.

### ТК-04. План бюджета и контроль суммы (шаг 5)

1. Открыть «План».
2. Попробовать разложить больше, чем есть.
3. Разложить по трём направлениям и подтвердить.

**Ожидается:** превысить бюджет невозможно — счётчики и ползунки ограничены
сверху; строка «Не разложено» обновляется на каждом шаге; до подтверждения план
можно менять; после подтверждения показывается сравнение плана с фактом.

### ТК-05. Обязательная покупка (шаг 7)

1. «Покупки» → «Каша» → «Купить за 20 Ф».

**Ожидается:** до подтверждения видны цена, тип расхода, влияние на питомца и
остаток после покупки; после покупки баланс уменьшился на 20, сытость выросла,
позиция появилась в истории недели.

### ТК-06. Необязательная покупка (шаг 7)

1. Купить «Наклейки» за 20 Ф.

**Ожидается:** позиция помечена как необязательный расход; радость выросла.

### ТК-07. Покупка при нехватке средств (шаг 7, обязательный к показу)

1. Потратить баланс до суммы меньше 45 Ф.
2. Нажать «Шапочка» (45 Ф).

**Ожидается:** покупка не выполняется, баланс не уходит в минус; показано, каких
именно фиников не хватает; предложены варианты, среди них «Отложить до следующей
недели» с подписью «Отказаться от желанного — это не ошибка».

### ТК-08. Цель и накопления (шаг 8)

1. «Копилка» → выбрать «Самокат для Финни».
2. Отложить 20 Ф.
3. Нажать «Снять из копилки», выбрать сумму.

**Ожидается:** видны стоимость, накопленное и остаток; до первого пополнения
срок не показывается; после пополнения появляется объяснение расчёта по средней
сумме; при снятии до подтверждения показано, как уменьшится копилка и на сколько
отодвинется цель; снятие требует отдельного подтверждения.

### ТК-09. Задания (шаг 6)

1. Пройти задание с верным ответом.
2. Пройти другое задание с неверным ответом.

**Ожидается:** объяснение выдаётся в обоих случаях; награда начисляется в обоих
случаях (за неточное решение — меньше); в демонстрационном режиме все задания
открыты сразу; доступны все пять видов взаимодействия, а не только выбор
варианта.

### ТК-10. Итоги недели и рост питомца (шаги 9–10)

1. «Завершить неделю» → изучить предварительный итог → подтвердить.
2. Повторить для пяти периодов подряд.

**Ожидается:** до закрытия недели ситуацию ещё можно исправить (кнопки «Докупить
нужное» и «Отложить в копилку»); после закрытия показаны разбор «Почему так
вышло» и «Следующий шаг»; за пять периодов питомец проходит не менее трёх
стадий; при неудачной неделе стадия не понижается.

### ТК-11. Сохранение прогресса (шаг 11)

1. Закрыть приложение полностью (смахнуть из списка задач).
2. Запустить заново.

**Ожидается:** питомец, баланс, покупки, накопления, цель и прогресс сохранены.

### ТК-12. Раздел для взрослого (шаг 12)

1. «Раздел для взрослого» → решить пример.
2. Проверить блоки, переключатели и удаление данных.

**Ожидается:** без верного ответа раздел не открывается; видны цели приложения,
пройденные темы и прогресс без негативных оценок; работают переключатели звука,
анимаций и демо-режима; сброс и удаление требуют подтверждения.

### ТК-13. Доступность

1. Увеличить системный размер шрифта до максимума.
2. Выключить анимации в разделе для взрослого.
3. Повернуть устройство.

**Ожидается:** текст увеличивается, вёрстка не ломается, ничего не обрезается;
анимации прекращаются; поворот не теряет прогресс; все состояния читаются без
опоры на цвет.

### ТК-14. Внешний вид редизайна

1. Пройти все экраны по очереди через нижние вкладки.
2. Открыть экраны поверх: задание, итоги недели, прогресс, словарик, раздел для
   взрослого.

**Ожидается:** заголовки и числа набраны Nunito, текст — Onest, кириллица не
подменяется системным шрифтом; у главных кнопок тёмная обводка и тень без
размытия, при нажатии кнопка «проваливается»; конверты бюджета имеют клапан;
кольцо цели на экране копилки заполнено соответственно накопленному; иконки
везде на месте и не превратились в пустые квадраты; нижняя панель вкладок не
перекрывает содержимое, активная вкладка выделена.

### ТК-15. Работа без сети

1. Включить режим полёта.
2. Пройти полный игровой цикл.

**Ожидается:** приложение работает полностью, прогресс не теряется.

## 4. Воспроизведение проверки

```bash
# 1. Автотесты и типы
cd web
npm ci
npm test
npx tsc -b

# 2. Сборка веб-слоя
npm run build

# 3. Сборка APK
cd ../android
./gradlew assembleRelease

# 4. Проверка подписи
$ANDROID_HOME/build-tools/35.0.0/apksigner verify --verbose --print-certs \
    app/build/outputs/apk/release/app-release.apk

# 5. Установка на устройство
adb install -r app/build/outputs/apk/release/app-release.apk
```
