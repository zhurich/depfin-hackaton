# Известные ограничения и план развития

Раздел 5, пункт 11 ТЗ.

---

## 1. Ограничения прототипа

### Игровая механика

| Ограничение | Последствие |
| --- | --- |
| Игровой период завершается только вручную | Нет привязки к календарю: «неделя» длится столько, сколько играет ребёнок. Для демонстрации это плюс, для длительного использования нужен выбор режима. |
| Непредвиденные расходы не реализованы | ТЗ допускает специально спланированные кейсы (например, расходы на лечение). Механика подготовлена — эффекты и объяснения уже есть, — но такого события в контенте нет. |
| Бонус за вход ограничен календарным днём | Вне демо-режима ребёнок получает не больше 10 Ф в день; при интенсивной игре доход почти полностью зависит от заданий. |
| Задания одноразовые | Всего 9 заданий. После прохождения всех основной доход — только периодический. Повторное прохождение не начисляет валюту. |
| Одна активная цель | Копить одновременно на несколько целей нельзя, хотя накопления по каждой цели хранятся отдельно. |

### Технические

| Ограничение | Последствие |
| --- | --- |
| Хранилище — `localStorage` | При очистке данных приложения через настройки Android прогресс теряется без предупреждения. Резервного копирования профиля внутри приложения нет. |
| Один локальный профиль | Несколько детей на одном устройстве одновременно играть не могут — только по очереди со сбросом. |
| Нет экспорта прогресса | Перенести профиль на другое устройство вручную нельзя (кроме системного переноса Android). |
| Нет iOS-версии | В обязательный минимум не входит; архитектура WebView + React позволяет добавить оболочку без переписывания логики. |
| Локализация только на русском | Строки лежат в коде вместе с контентом, механизма перевода нет. |

### Содержательные

- Внешность питомца — 80 комбинаций, но силуэтов всего четыре: разница между
  видами заметна, между палитрами — менее.
- Справочный раздел содержит 10 терминов; для полноценного словаря финансовой
  грамотности этого мало.
- Раздел для взрослого не даёт разбивки прогресса по неделям в виде графика —
  только числа и список тем.

## 2. План развития

### Ближайшие шаги (до финальной сдачи)

1. **Резервная видеозапись демонстрации** до трёх минут (ТЗ п. 4.1).
2. **Скриншоты и карточка RuStore** — по заготовке в
   [RUSTORE-LISTING.md](RUSTORE-LISTING.md).

### Следующая версия

1. **Непредвиденные расходы.** Событие раз в несколько периодов: неожиданная
   трата, которую нужно покрыть. Механика эффектов и объяснений уже есть, нужен
   контент и правило появления. Прямо предусмотрено ТЗ как допустимый кейс.
2. **Повторяемые задания.** Генерация однотипных задач с разными числами
   (сдача, распределение суммы) — чтобы навык закреплялся, а доход не иссякал.
3. **Экспорт и импорт профиля** одним файлом — страховка от очистки данных и
   способ переноса между устройствами.
4. **Несколько профилей** на одном устройстве с выбором при запуске.
5. **График прогресса в разделе для взрослого** — динамика по неделям без
   оценочных суждений.
6. **Расширение словаря** до 20–25 терминов со связями между статьями.

### Более дальняя перспектива

1. **Больше видов питомца и аксессуаров**, включая предметы, которые ребёнок
   покупает за накопления, — связь между целью и видимым результатом.
2. **Сезонные наборы заданий** — обновление контента без обновления приложения
   потребует загрузки контента извне; это меняет профиль приватности и требует
   отдельной проработки.
3. **Родительский кабинет.** В конкурсный минимум не входит и в прототипе
   отсутствует сознательно. При реализации потребуется обработка персональных
   данных — а значит, состав и цели обработки, сроки хранения, порядок удаления,
   правовое основание и технический механизм получения согласия законного
   представителя.
4. **iOS-версия** через ту же WebView-оболочку.
5. **Исследование с детьми 7–11 лет** для проверки понятности формулировок.
   Проводится только при надлежащем согласии законных представителей (ТЗ п. 8.4).

## 3. Что сознательно не делалось

Чтобы не подменять основную механику (ТЗ п. 2.7):

| Не делали | Почему |
| --- | --- |
| Подключение реальных счетов, карт, СБП, ГИС | Прямо исключено границами проекта |
| Платные подписки, внутриигровые покупки, реклама | Прямо исключено |
| Чаты, переписка между детьми, рейтинги | Прямо исключено |
| ИИ, машинное обучение, Big Data, облако | Не обязательны по ТЗ и не решают ни одной задачи этого прототипа |
| Серверная часть | Не требуется: игра офлайн |
| Публикация в RuStore | На этапе хакатона не требуется; техническая готовность обеспечена |
| Обфускация кода | ТЗ п. 7.2 требует полный исходный код без обфускации |
