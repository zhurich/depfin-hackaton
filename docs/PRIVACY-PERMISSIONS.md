> Раздел описывает Android-сборку, по которой идёт конкурсная сдача. Для
> iOS-оболочки выводы те же: в `Info.plist` нет ни одного ключа запроса
> разрешений, сетевых запросов приложение не делает, исключений App Transport
> Security нет. Отличается только место хранения профиля — файл внутри
> приложения вместо `localStorage`.

## Разрешения Android

**В манифесте приложения нет ни одного элемента `uses-permission`.**

Обязательный сценарий не требует камеры, микрофона, геолокации, контактов,
Bluetooth и хранилища. Даже разрешение `INTERNET` не запрашивается: веб-слой
лежит внутри APK и отдаётся локальным `WebViewAssetLoader`.

### Единственное разрешение в собранном APK

Инструмент `aapt2 dump badging` показывает в готовом APK одну строку:

```
uses-permission: name='ru.mosfin.finnipet.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION'
```

| Параметр | Значение |
| --- | --- |
| Источник | Библиотека `androidx.core` (добавляется автоматически при сборке) |
| Уровень защиты | `signature` — выдаётся только компонентам, подписанным тем же ключом |
| Назначение | Защита динамически регистрируемых `BroadcastReceiver` от доступа сторонних приложений на Android 13+ |
| Доступ к данным пользователя | Нет |
| Видимость для пользователя | Не отображается в списке разрешений приложения |

Это служебное самоограничение платформы, а не запрос доступа. Убрать его можно
только отказом от `androidx.core`; на приватность оно не влияет.

## Какие данные обрабатываются

### Собирается и хранится на устройстве

| Данные | Пример | Зачем |
| --- | --- | --- |
| Игровое имя ребёнка | «Капитан» | Обращение на главном экране |
| Игровое имя питомца | «Финни» | Отображение |
| Внешний вид питомца | три идентификатора | Отрисовка |
| Игровые числа | баланс, накопления, очки роста, показатели | Игровая механика |
| Журнал игровых операций | «Задание „Сколько сдачи“, +16 Ф» | Объяснение изменений баланса |
| Итоги игровых недель | план, факт, заметки | История и прогресс |
| Настройки | звук, анимации, демо-режим | Доступность |

### Не запрашивается и не хранится

Настоящее имя и фамилия, возраст, дата рождения, пол, телефон, e-mail, адрес,
фотографии, геолокация, контакты, идентификаторы устройства (IMEI, MAC, Android
ID), рекламные идентификаторы, платёжные данные и банковские реквизиты, сведения
о реальном семейном бюджете.

Поля для игровых имён прямо подписаны: «Придумай игровое прозвище — настоящее имя
писать не нужно», а на экране создания профиля выведен блок «Без регистрации».

## Куда передаются данные

**Никуда.** Приложение не делает сетевых запросов:

- нет разрешения `INTERNET`;
- весь контент отдаётся из `assets` через `WebViewAssetLoader`;
- внешние переходы заблокированы: `shouldOverrideUrlLoading` пропускает только
  собственный хост `appassets.androidplatform.net`;
- аналитики, SDK сбора статистики, крэш-репортинга и рекламных сетей в проекте
  нет (см. [LICENSES.md](LICENSES.md));
- серверной части у решения нет.

Согласие на обработку персональных данных не требуется, поскольку персональные
данные не обрабатываются.

| Механизм | Настройка | Почему так |
| --- | --- | --- |
| Android 12+ (`data_extraction_rules.xml`) | Облачная копия — **запрещена**, перенос на новое устройство — разрешён | Данные ребёнка не должны уходить в облако |
| Android 11 и ниже (`backup_rules.xml`) | Копирование разрешено | Механизм Android 12+ недоступен; данные анонимны |

## Чего в приложении нет

По границам проекта (ТЗ п. 2.7 и 3.5):

- реальных денег, банковских счетов, карт, СБП и платежей;
- платных подписок и внутриигровых покупок;
- рекламы и рекламных сетей;
- механик случайной платной награды;
- внешних ссылок, доступных ребёнку;
- публичных чатов, переписки между детьми, рейтингов и социальных функций;
- сбора и передачи телеметрии.

## Сброс и удаление профиля

Оба действия доступны взрослому без обращения к разработчику (ТЗ п. 3.5).

**Путь:** Главный экран → «Раздел для взрослого» → решить арифметический пример
→ блок «Данные на устройстве».

| Действие | Что происходит | Подтверждение |
| --- | --- | --- |
| **Сбросить профиль к началу** | Питомец, финики, копилка, задания и история возвращаются к исходному состоянию. Настройки, включая демонстрационный режим, сохраняются. | Да, отдельное окно |
| **Удалить все данные** | Профиль стирается из хранилища платформы (`localStorage` на Android, файл в Application Support на iOS); оболочка дополнительно очищает хранилище и кэш WebView и перезагружает приложение. Возврат к первому запуску. | Да, отдельное окно с пометкой о необратимости |

Дополнительно данные удаляются штатными средствами Android: «Настройки →
Приложения → Питомец Финни → Память → Очистить данные», а также при удалении
приложения.

## При дальнейшей публикации

Состав данных при публикации в RuStore не меняется: приложение остаётся
офлайн-решением без аккаунтов. Если в будущем появятся облачная синхронизация
или родительский кабинет, потребуется отдельно проработать состав и цели
обработки, сроки хранения, порядок удаления, правовое основание и технический
механизм получения согласия законного представителя ребёнка. Такой функциональности
в текущем прототипе нет.
